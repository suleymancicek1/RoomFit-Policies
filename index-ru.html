Политика конфиденциальности RoomFit

Последнее обновление: 23 ноября 2026

1. Введение

RoomFit — это приложение для проектирования и планирования комнат с использованием искусственного интеллекта. Эта политика конфиденциальности объясняет, как ваши персональные данные собираются, обрабатываются и защищаются при использовании нашего приложения.

Используя наше приложение, вы соглашаетесь с данной политикой конфиденциальности.

2. Какие данные мы собираем

2.1 Информация об аккаунте

При создании аккаунта мы собираем:

  • Адрес электронной почты (обязательно) — для верификации и связи
  • Имя (опционально) — для персонализации профиля
  • Фото профиля (опционально) — для персонализации профиля
  • Информация аккаунта Google — при входе через Google

2.2 Данные о комнатах и дизайн-проектах

Для основных функций приложения мы собираем:

  • Размеры комнаты — ширина, длина, высота потолка
  • Неподвижные элементы — двери, окна, радиаторы, кондиционеры, колонны
  • Информация о мебели — тип, размеры, названия
  • Фотографии комнат (опционально) — для предложений ИИ
  • Фотографии мебели (опционально) — для предложений ИИ
  • Сохранённые проекты — при сохранении рекомендаций ИИ

2.3 Технические данные

  • Информация об устройстве — модель, версия ОС
  • Статистика использования — для улучшения производительности
  • Отчёты об ошибках — для выявления и устранения проблем

⚠️ Данные, которые мы НЕ собираем

Мы НЕ собираем:

  • Данные о местоположении
  • Рекламные идентификаторы
  • Персональные финансовые данные
  • Данные аккаунтов социальных сетей (кроме входа Google)

3. Как мы используем ваши данные

  • Создание и управление вашим аккаунтом
  • Предоставление предложений по расстановке мебели с помощью ИИ
  • Сохранение и синхронизация ваших проектов
  • Улучшение производительности приложения
  • Выявление и устранение проблем
  • Связь с вами (поддержка, обновления)

4. Передача данных

4.1 Сервисы ИИ

Ваши фотографии комнат и мебели обрабатываются через сторонний API ИИ для генерации предложений по дизайну. Эти фотографии используются исключительно для генерации предложений и не сохраняются постоянно провайдером API.

Примечание: Провайдер API ИИ может изменяться. Следите за обновлениями на этой странице.

4.2 Поставщики услуг

  • Firebase Authentication: Верификация аккаунта и безопасность
  • Firebase Crashlytics: Отслеживание ошибок и стабильность
  • Google Cloud: Хранение данных и бэкенд-сервисы

4.3 Данные, которые мы НЕ передаём

❌ Мы НЕ передаём ваши данные:

  • Рекламодателям
  • Брокерам данных
  • Маркетинговым исследовательским компаниям
  • Другим третьим лицам (за исключением случаев, требуемых законом)

5. Хранение и удаление данных

  • Срок хранения: Пока ваш аккаунт активен
  • Право на удаление: Удалите все свои данные через функцию "Удалить аккаунт" в приложении или на этой странице

6. Безопасность данных

Мы принимаем следующие меры для защиты ваших данных:

  • Шифрование передачи данных HTTPS/TLS
  • Правила безопасности Firebase и контроль доступа
  • Регулярные проверки безопасности и обновления
  • Ограниченный доступ персонала

7. Конфиденциальность детей

Приложение предназначено для широкой аудитории. Для пользователей младше 16 лет рекомендуется родительский контроль. Родители или опекуны должны контролировать использование приложения детьми.

Если мы обнаружим, что были обработаны данные ребёнка младше 16 лет, мы немедленно удалим их.

  • Право на исправление
  • Право на удаление ("право быть забытым")
  • Право на ограничение обработки
  • Право на переносимость данных
  • Право на возражение
