Política de Privacidad de RoomFit

Última actualización: 23 de noviembre de 2026

1. Introducción

RoomFit es una aplicación de diseño y distribución de habitaciones impulsada por IA. Esta política de privacidad explica cómo se recopilan, procesan y protegen sus datos personales cuando utiliza nuestra aplicación.

Al utilizar nuestra aplicación, acepta esta política de privacidad.

2. Datos que Recopilamos

2.1 Información de la Cuenta

Al crear una cuenta, recopilamos:

  • Dirección de correo electrónico (obligatorio) - para verificación y comunicación
  • Nombre (opcional) - para personalización del perfil
  • Foto de perfil (opcional) - para personalización del perfil
  • Información de la cuenta de Google - cuando inicia sesión con Google

2.2 Datos de Habitaciones y Diseños

Para las funciones principales de la aplicación, recopilamos:

  • Medidas de la habitación - ancho, largo, altura del techo
  • Elementos fijos - puertas, ventanas, radiadores, aire acondicionado, columnas
  • Detalles de muebles - tipo, dimensiones, nombres
  • Fotos de habitaciones (opcional) - para sugerencias de IA
  • Fotos de muebles (opcional) - para sugerencias de IA
  • Diseños guardados - cuando guarda recomendaciones de IA

2.3 Datos Técnicos

  • Información del dispositivo - modelo, versión del sistema operativo
  • Estadísticas de uso - para mejorar el rendimiento de la aplicación
  • Informes de errores - para detectar y solucionar problemas

⚠️ Datos que NO Recopilamos

NO recopilamos:

  • Datos de ubicación
  • Identificadores publicitarios
  • Información financiera personal
  • Datos de cuentas de redes sociales (excepto inicio de sesión con Google)

3. Cómo Usamos Sus Datos

  • Crear y gestionar su cuenta
  • Proporcionar sugerencias de distribución de habitaciones con IA
  • Guardar y sincronizar sus diseños
  • Mejorar el rendimiento de la aplicación
  • Detectar y solucionar problemas
  • Comunicarnos con usted (soporte, actualizaciones)

4. Compartición de Datos

4.1 Servicios de IA

Sus fotos de habitaciones y muebles se procesan a través de una API de IA de terceros para generar sugerencias de diseño. Estas fotos se utilizan únicamente para generar sugerencias y no se almacenan permanentemente por el proveedor de la API.

Nota: El proveedor de la API de IA puede cambiar. Consulte esta página para actualizaciones.

4.2 Proveedores de Servicios

  • Firebase Authentication: Verificación de cuenta y seguridad
  • Firebase Crashlytics: Seguimiento de errores y estabilidad
  • Google Cloud: Almacenamiento de datos y servicios backend

4.3 Datos que NO Compartimos

❌ NO compartimos sus datos con:

  • Anunciantes
  • Agentes de datos
  • Empresas de investigación de mercado
  • Otros terceros (excepto cuando sea requerido por ley)

5. Retención y Eliminación de Datos

  • Período de retención: Mientras su cuenta esté activa
  • Derecho de eliminación: Elimine todos sus datos a través de la función "Eliminar cuenta" en la aplicación o esta página
  • Eliminación automática: Las cuentas inactivas se eliminan después de 2 años

6. Seguridad de los Datos

Tomamos las siguientes medidas para proteger sus datos:

  • Transmisión de datos cifrada con HTTPS/TLS
  • Reglas de seguridad de Firebase y controles de acceso
  • Análisis de seguridad y actualizaciones regulares
  • Acceso limitado del personal

7. Privacidad de los Niños

La aplicación está diseñada para un público general. Se recomienda supervisión parental para usuarios menores de 16 años. Los padres o tutores deben supervisar el uso de la aplicación por parte de sus hijos.

Si descubrimos que se han procesado datos de un menor de 16 años, los eliminaremos inmediatamente.

8. Sus Derechos bajo el RGPD (Ciudadanos de la UE)

Según el Reglamento General de Protección de Datos (RGPD), tiene los siguientes derechos:

  • Derecho de acceso a sus datos
  • Derecho de rectificación
  • Derecho de supresión ("derecho al olvido")
  • Derecho a restringir el procesamiento
  • Derecho a la portabilidad de datos
  • Derecho de oposición
  • Derecho a oponerse a la toma de decisiones automatizada

9. Cookies y Tecnologías de Seguimiento

Nuestra aplicación no utiliza cookies. Firebase Analytics y Crashlytics pueden recopilar datos de uso anónimos dentro de la aplicación.

10. Enlaces a Terceros

La aplicación puede contener enlaces a sitios web o servicios de terceros. No somos responsables de las políticas de privacidad de esos sitios.

11. Cambios en Esta Política

Esta política de privacidad puede actualizarse periódicamente. Los cambios importantes se comunicarán mediante notificaciones en la aplicación. Recomendamos revisar esta página regularmente.
