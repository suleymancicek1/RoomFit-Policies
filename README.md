## 🤖 Yapay Zekâ Kullanımı / AI Usage

Oda ve mobilya fotoğraflarınız, yapay zekâ önerileri için üçüncü taraf AI API'si aracılığıyla işlenir. Bu fotoğraflar yalnızca öneri üretimi için kullanılır ve API sağlayıcısı tarafından kalıcı olarak saklanmaz.

Your room and furniture photos are processed through a third-party AI API for design suggestions. These photos are used solely for suggestion generation and are not permanently stored by the API provider.

**Not:** Kullanılan AI API sağlayıcısı değişebilir. Güncel bilgiler için gizlilik politikası sayfalarını ziyaret edin.

**Note:** The AI API provider may change. Visit the privacy policy pages for up-to-date information.

## 🗑️ Hesap Silme / Account Deletion

Hesabınızı silmek için:
1. Uygulamayı açın
2. Profil → Hesabım → Hesabımı Sil
3. Veya yukarıdaki "Hesap Silme" linklerini kullanın

To delete your account:
1. Open the app
2. Profile → My Account → Delete Account
3. Or use the "Delete Account" links above
